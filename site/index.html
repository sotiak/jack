Sotiak Mono

Sotiak Monoは、IosevkaとBIZ UDゴシックをベースにした、
日本語対応の等幅フォントです。

比較

同じサイズ・同じ文字列で、Iosevka SS03 / JetBrains Mono / Consolas と比較。中央のバーをドラッグ、右のメニューで比較対象を切り替え。

Sotiak Mono Iosevka SS03 
fun main() {
  val s = "agijr WwtM 0O 1Il"
  val ok = s.length > 8
  if (ok) print(s) else println(s)
}
